# About QUB

**QUB** is a new class of AI-forward media container that treats **semantic understanding as first-class data**.

Unlike existing formats (MP4, MXF, Matroska), QUB stores not only audio and video, but the **AI-derived structure and meaning of media itself**—shots, scenes, dialogue, objects, faces, OCR, segmentation, embeddings, and full model provenance—persisted directly alongside the media.

QUB is designed around the principle:

> **Inference Once, Query Forever**

AI analysis is performed at ingest and embedded into the file, eliminating redundant inference and enabling **query-native editorial workflows**. Editors can search, filter, and reason about video content using semantic concepts—*not just timecode or filenames*.

For creatives, this means video becomes a **living, queryable asset**, not a passive file.  
For engineers, QUB provides a **byte-accurate, extensible container** where semantic data is temporally aligned, provenance-tracked, and interoperable across tools.

QUB is not an extension of an existing container.  
It defines a **new category of media format** built for AI-native workflows.
